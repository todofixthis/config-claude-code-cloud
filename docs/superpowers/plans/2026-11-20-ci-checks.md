# CI checks implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run five checks on every pull request to `todofixthis/config-claude-code-cloud`, as a safety net for agent-written changes.

**Architecture:** One new workflow, `.github/workflows/ci.yml`, with one job per check. Tool versions are pinned in the workflow and tracked by Renovate. `renovate.json` gains a migration and a regex manager, `generate-claude-md.yml` gains a path, and `README.md` documents the workflow and the one manual ruleset step. No pre-work: this change touches no agent guidance file.

**Tech Stack:** GitHub Actions, shellcheck, actionlint, Renovate, trufflehog.

**Spec:** `docs/superpowers/specs/2026-11-20-ci-checks-design.md`

**Worktree:** `/home/user/config-claude-code-cloud` (branch: `claude/exciting-wright-3j4a8t`). This is the session's own checkout, already on its mandated feature branch, in an ephemeral container. No separate worktree.

## Global Constraints

- Trigger on `pull_request` with no path filter.
- Workflow permissions: `contents: read`.
- Every job: `runs-on: ubuntu-24.04`, never `ubuntu-latest`.
- Every action is pinned to a commit digest with a version comment.
- Job names are fixed: `Shell scripts`, `Workflows`, `Renovate config`, `Secrets`, `Generated files`.
- No job uses a repository secret.
- trufflehog fails on verified results only.
- Commit messages follow `phx:creative-commits`. Push after each commit.
- Scratch files go in `$SCRATCH=/tmp/claude-0/-home-user-config-claude-code-cloud/0382c269-fe70-592a-9bb5-0834955ee83c/scratchpad`, never in the repo.

- [ ] **Step 1: Write `.github/workflows/ci.yml`**

```yaml
---
name: CI

on:
  pull_request: {}

permissions:
  contents: read

concurrency:
  group: ci-${{ github.event.pull_request.number }}
  cancel-in-progress: true

# Tool pins. Each `# renovate:` comment feeds renovate.json's regex manager
# for this file; keep the comment directly above its variable. Node is pinned
# in the Renovate config job, where Renovate's github-actions manager tracks it.
env:
  # renovate: datasource=github-releases depName=rhysd/actionlint extractVersion=^v(?<version>.+)$
  ACTIONLINT_VERSION: 1.7.12
  # renovate: datasource=npm depName=renovate
  RENOVATE_VERSION: 44.257.5
  # renovate: datasource=github-releases depName=trufflesecurity/trufflehog extractVersion=^v(?<version>.+)$
  TRUFFLEHOG_VERSION: 3.100.0

# Job names are the required status checks on main's ruleset: renaming one
# leaves a required check that never reports.
jobs:
  shell:
    name: Shell scripts
    # ubuntu-24.04, not ubuntu-latest: the preinstalled shellcheck comes from
    # Ubuntu's own packages, so its version changes only with this label.
    runs-on: ubuntu-24.04
    timeout-minutes: 10
    steps:
      - name: Checkout
        uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1
        with:
          persist-credentials: false

      - name: Run bash -n and shellcheck
        run: |
          mapfile -t scripts < <(git ls-files '*.sh')
          if [ "${#scripts[@]}" -eq 0 ]; then
            echo "❌ git ls-files found no *.sh files to check"
            exit 1
          fi
          echo "▶️ checking ${#scripts[@]} scripts with shellcheck $(shellcheck --version | awk '/^version:/ {print $2}')"
          for script in "${scripts[@]}"; do
            bash -n "$script"
          done
          shellcheck "${scripts[@]}"
          echo "✅ shell scripts pass"

  workflows:
    name: Workflows
    runs-on: ubuntu-24.04
    timeout-minutes: 10
    steps:
      - name: Checkout
        uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1
        with:
          persist-credentials: false

      - name: Install actionlint
        run: |
          base="https://github.com/rhysd/actionlint/releases/download/v${ACTIONLINT_VERSION}"
          tarball="actionlint_${ACTIONLINT_VERSION}_linux_amd64.tar.gz"
          cd "$RUNNER_TEMP"
          curl -sSfL --retry 3 -o "$tarball" "$base/$tarball"
          curl -sSfL --retry 3 -o checksums.txt "$base/actionlint_${ACTIONLINT_VERSION}_checksums.txt"
          # The checksums file comes from the same release: this catches a
          # corrupt download, not a compromised release.
          awk -v f="$tarball" '$2 == f' checksums.txt | sha256sum -c -
          tar -xzf "$tarball" actionlint
          echo "✅ installed actionlint ${ACTIONLINT_VERSION}"

      - name: Run actionlint
        run: |
          "$RUNNER_TEMP/actionlint"
          echo "✅ workflows pass"

  renovate:
    name: Renovate config
    runs-on: ubuntu-24.04
    timeout-minutes: 10
    steps:
      - name: Checkout
        uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1
        with:
          persist-credentials: false

      - name: Set up Node
        uses: actions/setup-node@949feb2413d6458794dcd2491c4babbbce0c15c1 # v7.1.0
        with:
          node-version: 24.22.3

      # No file argument: given one, the validator checks it as global config
      # rather than repo config.
      - name: Run renovate-config-validator
        run: |
          npx --yes --package "renovate@${RENOVATE_VERSION}" -- renovate-config-validator --strict
          echo "✅ renovate.json passes"

  secrets:
    name: Secrets
    runs-on: ubuntu-24.04
    timeout-minutes: 10
    steps:
      - name: Checkout
        uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1
        with:
          fetch-depth: 0
          persist-credentials: false

      # On pull_request the action scans base.sha to head.sha itself.
      # --results=verified: unverified results are pattern matches, and
      # unknown ones come from failed verification calls such as a network
      # error, so failing on either would fail PRs with nothing wrong in them.
      - name: Run trufflehog
        uses: trufflesecurity/trufflehog@d232362a64a09a9e7d58267b8f5acef00ae90e23 # v3.100.0
        with:
          extra_args: --results=verified
          version: ${{ env.TRUFFLEHOG_VERSION }}

  generated:
    name: Generated files
    runs-on: ubuntu-24.04
    timeout-minutes: 10
    steps:
      - name: Checkout
        uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1
        with:
          fetch-depth: 0
          persist-credentials: false

      # base...head diffs from the merge base, so regenerations the bot pushed
      # to main after this branch was cut don't count against it.
      - name: Check cloud/CLAUDE.md has no hand edits
        env:
          BASE_SHA: ${{ github.event.pull_request.base.sha }}
          HEAD_SHA: ${{ github.event.pull_request.head.sha }}
        run: |
          changed=$(git diff --name-only "${BASE_SHA}...${HEAD_SHA}" -- cloud/CLAUDE.md)
          if [ -n "$changed" ]; then
            echo "::error file=cloud/CLAUDE.md::cloud/CLAUDE.md is generated. Edit cloud/CLAUDE.cloud-only.md instead; a workflow regenerates cloud/CLAUDE.md after merge."
            echo "❌ this pull request edits cloud/CLAUDE.md"
            exit 1
          fi
          echo "✅ cloud/CLAUDE.md untouched"
```

The trufflehog `version` input is the `ghcr.io/trufflesecurity/trufflehog` image tag, which has no `v` prefix: `3.100.0` exists there and `v3.100.0` doesn't.

## Intentional Decisions

*(Populated during review — reviewers must not re-raise these)*

- Execution is inline: every task's file content is written out in full.
- The trufflehog `version` input is pinned and tracked, although the spec names only the actionlint and renovate pins. The action defaults it to `latest`, which would break the spec's third anti-goal.
- Node is pinned literally in `setup-node`, not through `env`. Renovate's `github-actions` manager tracks a literal `node-version` natively, and reads `${{ env.NODE_VERSION }}` as a bogus version.
