# Maintaining this file

This is `todofixthis/config-claude-code-cloud`'s `cloud/CLAUDE.cloud-only.md`. `todofixthis/config-claude-code-cloud`'s `cloud/CLAUDE.md` is generated by its `cloud/generate-claude-md.sh` — never edit `cloud/CLAUDE.md` directly, since regeneration overwrites it. The script concatenates this file (cloud-only content) with `cloud/CLAUDE.shared.md` (content shared with `todofixthis/config-claude`, canonical in `todofixthis/config-claude`, not in `todofixthis/config-claude-code-cloud` — see below).

Editing cloud-only content: change this file, in `todofixthis/config-claude-code-cloud`, run `cloud/generate-claude-md.sh`, commit `cloud/CLAUDE.md`, and push. Then bump the version comment in `cloud/pointer.sh`, and ask a human to re-paste `pointer.sh`'s content into the environment's Setup script field — no session can reach that dialog itself — to apply the change immediately rather than waiting for the ~7-day cache cycle. `todofixthis/config-claude-code-cloud`'s `cloud/setup.sh` is unaffected — it still fetches `cloud/CLAUDE.md` as one file; this split only changes how that file is built.

Editing shared content: `cloud/CLAUDE.shared.md` in `todofixthis/config-claude-code-cloud` is a synced copy, not canonical — `todofixthis/config-claude`'s `CLAUDE.shared.md` is. Change it in `todofixthis/config-claude` instead, on `main`: `todofixthis/config-claude`'s `.github/workflows/publish-shared-claude-md.yml` copies the change into `todofixthis/config-claude-code-cloud`'s `cloud/CLAUDE.shared.md`, regenerates `todofixthis/config-claude-code-cloud`'s `cloud/CLAUDE.md`, bumps `todofixthis/config-claude-code-cloud`'s `cloud/pointer.sh` version comment, and pushes automatically. A human still has to do the re-paste above afterward — nothing automates that.

Locally, `~/.claude/CLAUDE.md` is symlinked to a `todofixthis/config-claude` checkout, not a `todofixthis/config-claude-code-cloud` one — `todofixthis/config-claude`'s own `CLAUDE.md` is generated the same way, from its own local-only fragment plus its own canonical `CLAUDE.shared.md`.

A cloud session editing `~/.claude/CLAUDE.md` in place — `phx:reflection` deciding to record a new pattern, say — is editing the fetched copy: invisible everywhere else, and gone at the next cache rebuild. Make the edit in whichever source file above it belongs in instead.
