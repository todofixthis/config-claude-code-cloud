# Maintaining this file

This is `todofixthis/config-claude-code-cloud`'s `cloud/CLAUDE.cloud-only.md`. That repo's `cloud/CLAUDE.md` is generated by its `cloud/generate-claude-md.sh` — never edit `cloud/CLAUDE.md` directly, since regeneration overwrites it. The script concatenates this file (cloud-only content) with `todofixthis/config-claude-code-cloud`'s `cloud/CLAUDE.shared.md` (content shared with `todofixthis/config-claude`).

Editing cloud-only content: change this file, in `todofixthis/config-claude-code-cloud`. Editing shared content: that repo is also `cloud/CLAUDE.shared.md`'s canonical home — it's public, so both its own generation and `todofixthis/config-claude`'s fetch of it work without auth — so change it there, not in `todofixthis/config-claude`.

Either way, in a `todofixthis/config-claude-code-cloud` checkout: run `cloud/generate-claude-md.sh`, commit `cloud/CLAUDE.md`, and push. Then bump the version comment in `cloud/pointer.sh`, and ask a human to re-paste `pointer.sh`'s content into the environment's Setup script field — no session can reach that dialog itself — to apply the change immediately rather than waiting for the ~7-day cache cycle. That repo's `cloud/setup.sh` is unaffected — it still fetches `cloud/CLAUDE.md` as one file; this split only changes how that file is built.

Changed `todofixthis/config-claude-code-cloud`'s `cloud/CLAUDE.shared.md`? `todofixthis/config-claude`'s `generate-claude-md.sh` fetches it from GitHub, so it only picks up the change once the push above has landed. After that push: in a `todofixthis/config-claude` checkout, run its `generate-claude-md.sh`, then commit and push there too.

Locally, `~/.claude/CLAUDE.md` is symlinked to a `todofixthis/config-claude` checkout, not a `todofixthis/config-claude-code-cloud` one — `todofixthis/config-claude`'s own `CLAUDE.md` is generated the same way, from its own local-only fragment plus `todofixthis/config-claude-code-cloud`'s `cloud/CLAUDE.shared.md`.

A cloud session editing `~/.claude/CLAUDE.md` in place — `phx:reflection` deciding to record a new pattern, say — is editing the fetched copy: invisible everywhere else, and gone at the next cache rebuild. Make the edit in whichever source file above it belongs in instead.
